# 🔐 Caesar Cipher Lab

An interactive, offline educational web app for the Caesar Cipher (English + Arabic/RTL).
Built with HTML5, CSS3 and vanilla JavaScript — no dependencies, no backend.

## Features
Encrypt · Decrypt · Brute Force (26 shifts) · Frequency Analysis chart · Step-by-step learning mode · Rotating alphabet visualization · Quiz · Built-in self-tests

## Run locally
Download the files and open `index.html` in any browser (keep `index.html`, `style.css`, `script.js` in the same folder).
